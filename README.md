# افزونه مدیریت مقاله (مقاله‌یار)

افزونه‌ای برای مدیریت و غنی‌سازی محتوای مقالات وردپرس.

## امکانات

- درج محصولات همراه با مقالات مرتبط داخل محتوای مقاله
- ساخت کال تو اکشن (CTA)
- ساخت انواع جدول:
  - جدول مقایسه‌ای
  - جدول ساده
  - جدول اطلاعاتی
  - و سایر انواع جدول

## نصب

1. فایل `maghaleh-yar-2.2.0.zip` را دانلود کنید.
2. در وردپرس به مسیر **افزونه‌ها → افزودن → بارگذاری افزونه** بروید.
3. فایل zip را انتخاب و نصب کنید.
4. افزونه را فعال کنید.
